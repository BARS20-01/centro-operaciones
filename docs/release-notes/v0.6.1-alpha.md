# NEXUS PRIME v0.6.1-alpha

**Engineering Operations Nexus**  
Release candidate preparado el 2026-11-09 para validación en VPS-WEB y Coolify. No es una certificación de producción.

## Resumen

Esta versión prepara el despliegue Docker Compose para validación operativa y agrega System Diagnostics para mostrar el estado observable de la aplicación y su integración Docker. La lectura del Engine se realiza mediante Docker Socket Proxy; si no hay conectividad real, el producto conserva su comportamiento de datos simulados y Diagnostics lo identifica como tal.

## Cambios incluidos

- Página **System Diagnostics** accesible en `/diagnostics`, con estado `OK`, `WARN` o `ERROR` para Frontend, Backend, Docker Proxy, Docker Engine y Discovery Engine.
- Indicadores de versión Docker, cantidad de contenedores y última detección.
- Endpoints `/api/health` y `/api/diagnostics` para las comprobaciones de servicio.
- Healthchecks de Compose para web, API y proxy, y espera de salud de la API para iniciar el frontend.
- API ejecutada sin capacidades Linux adicionales y con `no-new-privileges`.
- Imagen predeterminada del Docker Socket Proxy Tecnativa v0.5.0 fijada por digest; solicitudes mutables del Engine permanecen deshabilitadas.
- Documentación de release y checklist de validación de VPS-WEB/Coolify.

System Diagnostics también se abrió en el navegador de desarrollo. En este entorno, la API respondió pero Docker no estaba disponible; la vista indicó Engine no verificable y fuente `SIMULATED`, sin mostrar un estado `LIVE` falso.

## Limitaciones y aceptación pendiente

- Este entorno no dispone de Docker CLI/Compose/daemon. No se verificaron el parsing de Compose, el build/arranque de las imágenes ni sus tamaños.
- No hubo acceso a Coolify ni al VPS-WEB; no se verificaron socket, healthchecks en ejecución, dominio, TLS, autenticación o telemetría Docker real.
- `v0.6.1-alpha` está preparado para la validación de VPS-WEB, pero el estado de producción sigue **NO CERTIFICADO**. Marcar `DEPLOYMENT READY` solo después de completar la [Deployment Validation Checklist](../deployment-coolify.md#deployment-validation-checklist).
- La API no implementa autenticación. Proteger el dominio y los metadatos de contenedores mediante políticas de acceso en el ingress o una capa equivalente.
