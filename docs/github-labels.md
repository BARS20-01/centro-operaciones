# Etiquetas de GitHub

Catálogo propuesto para clasificar issues y pull requests de NEXUS PRIME. Este archivo documenta las etiquetas; no las crea ni sincroniza en GitHub. Un mantenedor debe verificar las existentes y crear o actualizar las restantes en la configuración del repositorio.

| Etiqueta | Uso |
|---|---|
| `bug` | Comportamiento incorrecto o regresión reproducible. |
| `enhancement` | Funcionalidad nueva o mejora de capacidades existentes. |
| `documentation` | Correcciones o ampliaciones de documentación. |
| `performance` | Rendimiento, consumo de recursos o escalabilidad. |
| `ux` | Usabilidad, accesibilidad o experiencia visual. |
| `integration` | Adaptadores, contratos o conexión con sistemas externos. |
| `security` | Endurecimiento o trabajo de seguridad que pueda tratarse públicamente. |

Las etiquetas pueden combinarse. No publiques detalles de vulnerabilidades explotables, credenciales ni datos sensibles en un issue público; coordina su reporte privado con el propietario del proyecto. No se ha configurado todavía un canal privado en este repositorio.
